Help · Setup · Protocol

Browser requirements

  • Chromium-based Chrome / Edge 89+ (Web Serial). Firefox/Safari: simulator works, serial disabled.
  • Web Serial needs a secure context: https://, localhost, or opening this HTML file directly (file://).
  • On Linux add your user to the dialout group to access USB serial adapters.

Simulator quick start (no hardware)

  • Mode is Simulator by default: durations are in seconds, accelerated ×10 (select ×1 / ×10 / ×60).
  • Press Start → confirm → the batch runs Feeding → Aeration → Settling → Withdrawal → Idle, then repeats: Loop ∞ runs until Stop/Pause, or a fixed cycle count — set in Cycle configuration.
  • All inputs (durations, setpoints, gauge ranges, logging) persist in localStorage.

Connecting real hardware

  • USB-serial bridge (CP210x / FTDI / CH340) — click Choose port…, pick the device, select baud, Connect.
  • Switch mode to Real: durations are entered in minutes (or hours). Time scale is 1×.
  • Switch to Real before starting. Mode is locked while a cycle runs.

Serial protocol

device → host (1–5 Hz, LF-terminated):
  pH:7.21,T:24.5,DO:6.3,S1:0

host → device (sent on every actuator change):
  HEATER:1   HEATER:0
  SONICATOR:1   SONICATOR:0
  ACID:1   ACID:0
  BASE:1   BASE:0

A full Arduino example is in README.md shipped with this dashboard.

Control logic

  • Heater: ON when T < SP − DB, OFF when T > SP + DB (hysteresis).
  • Acid: ON when pH > SP + DB, OFF when pH < SP − DB. Base: mirrored below its SP.
  • Interlocks: acid and base never run together; every relay observes a minimum OFF-time; sonicator is hard-gated to Feeding and duty-cycles (ON s / OFF s).
  • E-STOP: kills all outputs instantly (bypasses relay guard) and halts the sequence; latch must be cleared manually.
